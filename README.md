# 团子 Dango

团子（Dango）是一个零第三方依赖的局域网聊天室。在一台电脑运行服务，同一局域网里的人用浏览器打开即可自助建房、发消息和传文件。

- 多房间：口令即房间。创建房间时系统分配一个 4 位数字口令（可自改），别人填口令和昵称即可加入，房间之间数据完全隔离
- 一个人可同时加入多个房间：顶栏“房间”按钮打开房间抽屉切换（默认收起，按钮上带聚合未读角标），可随时退出某个房间
- 文本消息、文件传输（带上传进度）、图片直接预览
- 左侧实时显示在线成员，窄屏下折叠为抽屉
- 跟随系统的浅色 / 深色主题
- 管理后台 `/admin`：查看房间列表、每个房间的成员昵称和 IP、人数、消息条数，可删除房间、踢人
- 两台 Mac 用雷电线直连也可以使用，见 [docs/thunderbolt-bridge.md](docs/thunderbolt-bridge.md)

## 要求

- 两台电脑连接同一个局域网
- 主机安装 Node.js 18 或更高版本

## 启动

在主机电脑执行：

```bash
cd ~/Workspace/tools/dango
npm start
```

终端会显示房间口令以及类似下面的局域网地址（方括号里是网卡，雷电直连时会标出"雷电网桥"）：

```text
局域网访问 [en0]: http://192.168.1.23:3000?token=xxxxxxxx
局域网访问 [雷电网桥 Thunderbolt Bridge]: http://169.254.10.5:3000?token=xxxxxxxx
```

将完整地址发给另一台电脑。两台电脑分别用浏览器打开地址、填写昵称，即可聊天和传文件。

按 `Ctrl+C` 停止服务。主机停止或休眠后，其他电脑将无法使用。

## 可选配置

```bash
ADMIN_TOKEN=my-secret PORT=8080 MAX_FILE_SIZE=209715200 npm start
```

- `ADMIN_TOKEN`：管理后台口令；未指定时，每次启动随机生成。
- `PORT`：服务端口，默认 `3000`。
- `MAX_FILE_SIZE`：单个文件最大字节数，默认 100 MB。
- `HOST`：监听地址，默认 `0.0.0.0`，以便局域网设备访问。

房间口令是 4 位数字，由创建者设定或系统随机分配，不需要在启动参数里配置。

## 数据与安全边界

- 每个房间的文件保存在主机的 `data/rooms/<房间ID>/`，不会提交到 Git。删除房间会连同其文件一起清除。
- 聊天消息和房间都保存在内存中，服务重启后全部清空；重启前已上传的文件目录仍留在磁盘。
- 管理后台只展示元信息（房间、成员昵称与 IP、人数、消息条数、文件数），看不到聊天正文和文件内容。
- 房间口令是 4 位数字，只用于在可信局域网里区分房间，不是强密码（一万种组合可被暴力尝试）。当前版本没有 HTTPS 和端到端加密，只适合可信局域网。加密方案的调研见 [docs/encryption.md](docs/encryption.md)。
- 管理员口令等同于后台钥匙，别外传。
- 不要把服务端口映射到公网。
